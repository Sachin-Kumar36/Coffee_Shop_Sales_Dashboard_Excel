# ☕ Coffee Shop Sales Dashboard – Excel

An interactive Coffee Shop Sales Dashboard created in Microsoft Excel to analyze sales performance and customer/order trends.

## 📊 Dashboard Features

- Total Sales KPI
- Total Footfall KPI
- Average Bill per Person
- Average Order per Person
- Quantity Ordered by Hours
- Category-wise Sales Distribution
- Size-wise Order Distribution
- Footfall & Sales by Store Location
- Top 5 Products by Sales
- Orders by Weekday
- Month Name Slicer
- Day Name Slicer

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Excel Formulas
- Data Analysis
- Data Visualization

## 📁 Dataset

This project uses a **Coffee Shop Sales dataset containing 5,000 rows of transaction data**.

The dataset includes:

- Transaction Date & Time
- Store Location
- Product Category
- Product Type
- Size
- Quantity
- Unit Price
- Sales
- Footfall

**Dataset Size: 5,000 rows**

## 🎯 Objective

The objective of this project is to analyze coffee shop sales data and create an interactive dashboard that provides useful insights into sales, customers, products, locations, and ordering patterns.

## 📈 Key Analysis

The dashboard helps analyze:

- Overall sales performance
- Customer footfall
- Average bill per person
- Average order per person
- Hourly order trends
- Category-wise sales
- Size-wise orders
- Store location performance
- Top 5 products by sales
- Weekday order patterns
